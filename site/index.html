Install

  1. Download and run Arakshan_Setup.exe. It installs the app and creates your data folders (default: Documents\Arakshan).
  2. When Setup asks for Cloud connection, paste your Airtable and ImageKit details (or leave it empty and add them later in Settings).
  3. Finish, and start Arakshan. It connects by itself on the first start and keeps the details privately.
  4. Later updates: Settings → Updates → Check for updates.

Windows may warn you

The program is not signed with a paid certificate, so Windows SmartScreen can show “Windows protected your PC”. Choose More info → Run anyway. To be sure the file is genuine, compare its SHA-256 below with: certutil -hashfile Arakshan.exe SHA256
